## About the Physics Project Days

## Higgs Project
The aim of the Higgs project is to give students an introduction to how analyses are performed in particle physics.
The project focuses on the $H \rightarrow 4\ell$ channel and makes use of CMS open data from Run 1 and gets students to recreate one of the Higgs discovery plots. 

### Running the Project
The project is structured around two exercises: 
1. The first consists of an introduction to python, with notebooks in French and English. See [`Introducton_to_python.ipynb`](https://github.com/ZakLawrence/Physics-Project-Days/blob/7fd8b407d6553e8a1d25d441336d2b41ba062760/Notebooks/Introduction_to_Python.ipynb) and [`Introducton_to_python_english.ipynb`](https://github.com/ZakLawrence/Physics-Project-Days/blob/7fd8b407d6553e8a1d25d441336d2b41ba062760/Notebooks/Introduction_to_Python_english.ipynb) respectively.
2. The second part of the project involves running through the Higgs analysis, again with notebooks in French and English. See [`HiggsAnalysis_start_french.ipynb`](https://github.com/ZakLawrence/Physics-Project-Days/blob/7fd8b407d6553e8a1d25d441336d2b41ba062760/Notebooks/HiggsAnalysis_start_french.ipynb) and [`HiggsAnalysis_start_english.ipynb`](https://github.com/ZakLawrence/Physics-Project-Days/blob/7fd8b407d6553e8a1d25d441336d2b41ba062760/Notebooks/HiggsAnalysis_start_english.ipynb)
